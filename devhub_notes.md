# 💻 DevHub Workspace

**DevHub** — это персональное локальное рабочее пространство (Workspace) разработчика, созданное на базе **Kotlin** и **Compose Desktop**. Приложение позволяет структурировать работу над локальными проектами на ПК, сканировать их метаданные, вести изолированные заметки и списки задач, автоматизировать запуск скриптов и хранить важные ссылки под рукой.

---

## 🛠️ Архитектура и План декомпозиции

Проект спроектирован по модульному принципу с четким разделением ответственности. Каждый экран и логический менеджер вынесены в отдельные независимые файлы для предотвращения связности кода.

```text
com.example.devhub/
│
├── data/                       # Слой данных (Сканирование ПК, локальные файлы)
│   ├── ProjectConfigRepository.kt # Управление списком папок и глобальным файлом `.devhub_config.json`
│   ├── ProjectAnalyzer.kt      # Сканирование файлов, подсчет строк кода, детекция Git и технологий
│   ├── ProjectNotesRepository.kt  # Чтение/запись файлов заметок `.md` внутри проектов
│   ├── ProjectTasksRepository.kt  # Чтение/запись файлов Канбан-задач `.txt` внутри проектов
│   ├── ProjectLinksRepository.kt  # Чтение/запись локальных списков URL-ссылок для каждого проекта
│   ├── CommandRunner.kt        # Утилита запуска системных процессов (ProcessBuilder) и открытия браузера
│   └── TaskModels.kt           # Модели данных для Канбан-задач и веб-ссылок
│
├── ui/                         # Слой интерфейса (Декларативный UI на Compose)
│   ├── components/             # Мелкие изолированные элементы интерфейса
│   │   ├── NavigationSideBar.kt # Боковая панель навигации (📁, 📝, 📋, ⚡, 🔗, 🛠️)
│   │   └── ProjectListPanel.kt  # Панель списка проектов с кнопками выборочного удаления
│   │
│   └── screens/                # Полноэкранные модули приложения
│       ├── InfoScreen.kt       # Главный экран: Карточка и метаданные проекта с ПК
│       ├── NotesScreen.kt      # Экран заметок: Полноэкранный текстовый редактор `.md`
│       ├── KanbanScreen.kt     # Экран задач: Интерактивная Канбан-доска со стрелками [◀] [▶]
│       ├── ScriptsScreen.kt    # Экран автоматизации: Script Runner и быстрые команды
│       ├── LinksScreen.kt      # Экран ресурсов: Быстрые веб-ссылки проекта с авто-открытием
│       └── SettingsScreen.kt   # Экран настроек: Управление темами и очистка кэша
│
└── main.kt                     # Точка входа (Фиксированный размер окна, запуск приложения)
```

## 🚀 Актуальный бэклог разработки (План задач)

### ЗАДАЧА 1: ИНФО-ПАНЕЛЬ НА ГЛАВНОЙ (ВМЕСТО ЗАМЕТОК)
- [ ] **Замена интерфейса:** При выборе проекта вместо серого текстового поля рендерить структурированную карточку метаданных.
- [ ] **Сбор данных с ПК:** Вывод полного пути к выбранной папке на жестком диске.
- [ ] **Сканирование папки:** Подсчет общего количества файлов внутри проекта (с игнорированием служебных директорий вроде `build` и `node_modules`).
- [ ] **Детекция технологий:** Распознавание стека по расширениям файлов (Kotlin, HTML5, CSS3, JavaScript/TypeScript).
- [ ] **Тайм-трекинг:** Вывод даты и времени добавления проекта в систему DevHub.
- [ ] **Интеграция с Git:** Автоматическая проверка наличия скрытой папки `.git`. Вывод зеленого текста `Git: Инициализирован` при наличии, или серого `Без Git` при отсутствии.
- [ ] **Быстрый запуск в IDE:** Реализация кнопки «Открыть в IntelliJ / VS Code» через системный `ProcessBuilder` для мгновенного старта работы над кодом.

### ЗАДАЧА 2: ОТДЕЛЬНАЯ ВКЛАДКА ДЛЯ ЗАМЕТОК
- [ ] **Пятая кнопка навигации:** Добавление иконки блокнота (`📝`) в левое меню.
- [ ] **Полноэкранный редактор:** Создание изолированного экрана, где текстовое поле ввода занимает всё доступное пространство для написания инструкций, гайдов и мыслей к проекту.

### ЗАДАЧА 3: ВЫБОРОЧНОЕ УДАЛЕНИЕ ПРОЕКТА
- [ ] **Кнопка-крестик:** Добавление интерактивного элемента `❌` напротив каждой папки в списке «Мои папки».
- [ ] **Безопасное удаление:** При нажатии проект полностью стирается из локальной конфигурации `.json` и пропадает с экрана, но сама физическая папка с исходным кодом на компьютере остается нетронутой.

### ЗАДАЧА 4: НАСТРОЙКИ И ТЕМЫОФОРМЛЕНИЯ
- [ ] **Полный сброс:** Кнопка тотальной очистки кэша, физически удаляющая скрытый файл `.devhub_config.json` из домашней директории ПК.
- [ ] **Резервное копирование:** Кнопка «Сохранить резервную копию списка» для быстрого копирования файла конфигурации на Рабочий стол или в выбранную папку.
- [ ] **Темизация (Dark/Light):** Реализация реактивного переключателя тем оформления для изменения палитры всего интерфейса (цвета панелей, текста и карточек) одной кнопкой.

### ЗАДАЧА 5: ВКЛАДКА БЫСТРЫЕ ССЫЛКИ (РЕСУРСЫ)
- [ ] **Экран ссылок:** Создание отдельной вкладки (`🔗`), где для каждого проекта хранится персональный список URL (Figma, GitHub, документация API).
- [ ] **Интеграция с браузером:** Реализация функции авто-открытия ссылок в стандартном браузере операционной системы по клику на карточку ресурса.

## 💻 Технологический стек

*   **Язык программирования:** Kotlin (JVM)
*   **UI Фреймворк:** Compose Multiplatform for Desktop (Declarative UI)
*   **Сборщик проектов:** Gradle
*   **Управление процессами ОС:** Java `ProcessBuilder`, `java.io.File`, `java.awt.Desktop`
