# 💻 DevHub Workspace

**DevHub** — это локальное рабочее пространство разработчика, созданное на базе **Kotlin** и **Compose Desktop**. Приложение позволяет структурировать проекты на ПК, выводить метаданные (Git, технологии), вести изолированные заметки, управлять задачами через Канбан-доску и запускать скрипты автоматизации автоматизации.

---

## 🛠️ Архитектура и Структура файлов

Проект реализован по модульному принципу. Логика работы с операционной системой и интерфейс полностью разделены по пакетам:

```text
com.example.devhub/
│
├── data/                       # Слой данных (Сканирование ПК, локальные файлы)
│   ├── ProjectConfigRepository.kt # Управление списком папок и глобальным файлом `.devhub_config.json`
│   ├── ProjectAnalyzer.kt      # Сбор метаданных с ПК, детекция Git и технологий по расширениям
│   ├── ProjectNotesRepository.kt  # Чтение/запись файлов заметок `.md` внутри папок проектов
│   ├── ProjectTasksRepository.kt  # Чтение/запись файлов Канбан-задач `.txt` внутри проектов
│   ├── CommandRunner.kt        # Утилита запуска системных процессов (ProcessBuilder) и Проводника
│   └── TaskModels.kt           # Модели данных
│
├── ui/                         # Слой интерфейса (Декларативный UI на Compose)
│   ├── components/             # Мелкие изолированные компоненты
│   │   └── NavigationSideBar.kt # Боковая панель навигации на системных эмодзи (📁, 📝, 📋, ⚡, 🛠️)
│   │
│   └── screens/                # Полноэкранные модули приложения
│       ├── MainWorkspaceScreen.kt # Главный диспетчер (Боковое меню и логика переключения)
│       ├── InfoScreen.kt       # Инфо-панель: Сбор данных проекта с ПК вместо серого текстового поля
│       ├── NotesScreen.kt      # Экран заметок: Полноэкранный изолированный текстовый редактор
│       ├── KanbanScreen.kt     # Экран задач: Интерактивная тёмная Канбан-доска с розовой кнопкой
│       ├── ScriptsScreen.kt    # Экран автоматизации: Script Runner для быстрого запуска команд
│       └── SettingsScreen.kt   # Экран настроек: Сброс конфигурации приложения и управление темами
│
└── main.kt                     # Точка входа (Фиксированный размер окна 900x600, превью `DevHubPreview`)
```
